# 节日主视觉

一次任务只做一个节日（或节气）的一批 6 张图。目标是内部同事愿意直接发布的主视觉：一眼是 NBA，再看是这个节日，明亮、有篮球的激情，而且不俗。

## 每张图的三要素

1. **巧妙结合**：节日的含义由一个 NBA 资产本身承担，见 [design.md](design.md)。
2. **一句文案**：和画面的机关说同一件事，印在画面里，见 [copy.md](copy.md)。
3. **官方 Logoman**：img2.5 参照官方参考图直接画进画面，见 [logoman.md](logoman.md)。

三要素都放在 NBA 的品牌调性里：表达篮球运动的激情，色彩明亮、积极，见 [design.md](design.md#品牌调性)。

## 节奏

整批控制在 15 分钟左右。最拖时间的是构思时反复推翻、边想边搜，所以：

- 检索只做两轮，每轮一次性并行发出。两轮之后不再检索。
- 构思先列候选，再从候选里选。不满意就从剩下的候选里换，不回头重新发散。
- 想法做到"一眼 NBA、再看是节日、明亮有劲、不俗"就可以用，不追求想出最好的那一个。拿不准的交给第 6 步看图验收。
- 不在思考里长篇推演。候选和概念卡直接写进文件。

## 工作流

复制这份清单，逐项完成：

```text
- [ ] 1. 读任务：节日、补充要求、此前概念、此前来源
- [ ] 2. 检索：两轮并行，至少 6 个真实页面，写下 3 条节日洞察
- [ ] 3. 概念卡：列 10 个候选，选 6 个写卡，过一遍自检表
- [ ] 4. 写 prompt：每张一段英文 prompt
- [ ] 5. 生图：scripts/generate.py
- [ ] 6. 验收：六张看完再决定重做哪几张，一起重跑
- [ ] 7. 回信封
```

### 1. 读任务

任务里会给出节日名称、日期、地区、含义，以及两段附加信息：

- **同事的补充要求**：本批必须落实。落实方式见 [design.md](design.md#补充要求)。
- **此前批次的概念与来源**：本批不要重复此前的概念，来源尽量换新。

"重复"只指两种情况：主资产和机关都相同，或者文案相同。同一个资产换一种机关，或者同一种机关换一个资产，都不算重复，可以放心用。

### 2. 检索

按 [research.md](research.md) 检索，分两轮完成：

1. 一次性并行发出 6 到 8 个搜索，三条线都要覆盖。
2. 从结果里挑 6 到 8 个页面，一次性并行打开。

两轮之后不再检索。构思时发现某个想法缺少依据，就换一个现有来源撑得住的想法，不要为它单独去搜。只有一种例外：某一条线完全没有可用的页面，可以补一轮，最多 2 个页面。

产出 3 条节日洞察：这个节日里人们真实在做的事，而不是节日符号。

### 3. 概念卡

1. 按 [design.md](design.md) 列 10 个候选，每个一行：`主资产 | 机关 | 文案`。
2. 从中选 6 个，按下表各写一张卡，写进 `/tmp/cards.md`。
3. 过一遍自检表。某项不满足，就从剩下的候选里换一个，换完即定稿。

| 字段 | 内容 |
|---|---|
| 洞察 | 取自第 2 步的哪条洞察 |
| 灵感 | 取自第 2 步的哪条来源，借了它的什么方法 |
| 主资产 | 一个 NBA 资产 |
| 机关 | 一句话说清双重读法：它是什么，同时又是什么 |
| 文案 | 画面上的精确原文，见 [copy.md](copy.md) |
| 风格 | 从 [styles.md](styles.md) 选一种 |
| Logoman | 放法与位置，见 [logoman.md](logoman.md) |

自检表：

- [ ] 六个机关互不重复，也不重复此前批次
- [ ] 没有使用 design.md、copy.md、prompting.md 里的示例概念或示例文案，也没有只换数字或单词沿用它们
- [ ] 六种风格互不相同，主资产至少四种
- [ ] 每张的节日含义都由 NBA 资产本身承担，没有并排摆放的节日符号
- [ ] 每张都有一句文案，而且和机关说的是同一件事
- [ ] 每张都有篮球的动势或热度，主色明亮、积极，没有以黑、深蓝、灰为主调的画面
- [ ] 每张的洞察或灵感都对应一条本批真实打开过的来源
- [ ] 有补充要求时，六张都落实了

### 4. 写 prompt

按 [prompting.md](prompting.md) 的结构写英文 prompt。每张都必须写明文案的精确原文，并包含 [logoman.md](logoman.md#标准句) 里的 Logoman 标准句。

### 5. 生图

把六段 prompt 写进 `prompts.json`，格式为 `[{"id": 1, "prompt": "..."}]`，然后运行：

```bash
python festival-poster/scripts/generate.py prompts.json results.json --out-dir /tmp/posters
```

脚本做四件事：

- 调用 `gpt-image-2.5-sunburst`，尺寸 `1024x1536`。
- 自动附上官方 Logoman 参考图 `assets/logoman-reference.png`。
- 六张同时生成，失败的自动重试一次。
- 把成图存到 `--out-dir` 供你查看，`content_url` 写入 `results.json`。

密钥由 Cursor 后台的 Secrets 注入为环境变量 `AIHUBMIX_API_KEY`，脚本直接读取。不要回显、保存或复述密钥。脚本报 `AIHUBMIX_API_KEY is not set.` 时不要自己找密钥或换其他生图方式，直接在信封的 `===NOTES===` 里写明这条错误，`===POSTERS===` 返回空数组 `[]`。

### 6. 验收

一次性打开 `--out-dir` 里的六张图，对照下表检查：

| 检查项 | 不合格的样子 |
|---|---|
| 机关 | 需要解释才看懂，或者变成了元素并排 |
| NBA 辨识 | 只是一张普通篮球图 |
| 调性 | 整体偏暗、偏灰，或者冷清、孤独、深夜空场的情绪 |
| 文案 | 错字、漏字、多字，出现文案以外的字，或者文字压住 Logoman、机关 |
| Logoman | 比例、左蓝右红、白色剪影、白色描边与参考图不一致；被裁切、遮挡、变形；出现第二个标志 |
| 质感 | 塑料感、过度光效、漂浮物体、廉价渐变 |
| 风格 | 和同批另一张撞了 |

六张都看完，再把不合格的几张一起写进一个新的 prompts 文件，只改出问题的部分，一次重跑。同一张最多重做两次。两次之后还不理想，就从已生成的几版里挑最好的一版交付。

`content_url` 约 30 分钟失效，最后一次生成完成后尽快回信封。

### 7. 回信封

按 [reference/output-envelope.md](../reference/output-envelope.md) 返回，信封之外不输出任何内容。
