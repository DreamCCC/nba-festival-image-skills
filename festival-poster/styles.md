# 风格池

一批六张，每张一种风格，六张互不相同。从下表挑选，也可以按检索结果换成同等水准的风格。挑选时让媒介、主色和构图拉开距离，主色调至少三组。

| 风格 | prompt 里要写的画面语言 | 常见文字 |
|---|---|---|
| 静物摄影 | studio still life, soft top light, seamless paper, real material texture, large negative space | 可无 |
| 纪实体育摄影 | 35mm film, available light, empty arena, natural grain, out-of-focus foreground | 无 |
| 瑞士字体海报 | Swiss grid, one enormous condensed grotesk word, two flat inks, strict margins | 有 |
| Risograph 双色印刷 | two-colour risograph, uncoated paper, halftone dots, slight misregistration | 可无 |
| 复古票根与场刊 | letterpress on cream card stock, ink spread, perforation, creases, overhead photo | 有 |
| 杂志封面 | editorial cover layout, masthead-style headline, one photographic subject | 有 |
| 版画 | woodcut or linocut, carved marks, bold black and one spot colour | 可无 |
| 纸艺浮雕 | layered paper relief, raking side light, monochrome or near-monochrome | 无 |
| 微缩模型 | believable miniature diorama, shallow depth of field, handmade details | 无 |
| 极简几何 | constructivist shapes, flat colour, one shape carries the metaphor | 可无 |
| 东方留白 | ink wash on xuan paper, vast negative space, dry-brush strokes；只用于中国节日 | 无 |

## 文字

文字也是风格的一部分。六张里带字和无字的作品各至少两张，由风格决定哪张带字。

- 文字是版式或物件本身的一部分，例如海报标题、票面、球衣名字栏，不是贴上去的祝福语。
- 英文不超过 6 个词，优先全大写短词。中文不超过 6 个字，字越少越稳。
- 在 prompt 里用引号写出精确原文，并写明 `exactly and only`。同时写明字体气质和位置。
- 不写 NBA 字标、球队名、球员名和赞助商。文字不压在 Logoman 上。
- 无字作品在 prompt 末尾写 `No text, no letters, no numbers`。数字本身是机关时例外。
